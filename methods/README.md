# Methods

Prose descriptions of analytical methods, results, and interpretation boundaries across
this repository.

Start with the shared [biological interpretation guide](biological_interpretation.md)
for measurement units, evidence provenance, defensible wording, and caption/review
requirements across every analysis. The companion
[claim audit](biological_interpretation_audit.md) covers current prose and
generators, PR #173's overlays, PR #192's archived Rosalind discussion/review, and
milestone documentation. These rules apply to manuscript and public descriptions
as well as methods.

| Document | Scope |
| --- | --- |
| [`biological_interpretation.md`](biological_interpretation.md) | Shared interpretation guide: evidence chain, measurement units, direction distinctions, minimum reporting contract, and worked examples |
| [`biological_interpretation_audit.md`](biological_interpretation_audit.md) | Project-wide claim audit across methods, captions, PRs, generators, and milestone documentation |

Individual analysis scripts (e.g., in `scripts/` and `src/bsdbng/`) document their
respective workflows, Justfile recipes, and BugSigDB vintages following the
shared biological interpretation guide.
