# Trait Profile Investigation

This folder contains the current v2 trait-profile investigation outputs and
supplemental profile-condition/profile-contrast diagnostics.

## Regenerate Current Outputs

Run the complete current investigation with:

```bash
just trait-profile-investigation
```

Equivalent direct command:

```bash
uv run python scripts/regenerate_trait_profile_investigation.py
```

The regeneration command writes the current v2 output folders, summary diagram,
all-BugSigDB direction maps, direction-grid TSV, figure annotations, and the
PowerPoint deck media.

The current workflow diagram uses `waldronlab/BugSigDBExports` `v1.3.1`
`full_dump.csv` (`BugSigDB 2026-04-24_00:41_UTC`, DOI
`10.5281/zenodo.19740674`) as the citable BugSigDB input. The plotted Sankey
corpus is restricted to `Homo sapiens` host samples only: 5,829 profiles from
1,080 studies. Trait scores are log1p-scaled profile trait fractions converted
to column z-scores, and paired trait contrasts use one-sample t-tests with
Benjamini-Hochberg q-values.

## Current v2 Outputs

These folders define the current project story and are the source for
`trait_profile_investigation_figures.pptx`.

| folder | parent focus | generator | role |
| --- | --- | --- | --- |
| `aerobe-enrichment-v2/` | aerobe signal in increased profiles | `scripts/investigate_facultative_aerobe_expansion.py` | Current aerobe-side v2 analysis using selected oxygen-tolerance traits. |
| `anaerobe-depletion-v2/` | anaerobe signal in decreased profiles | `scripts/investigate_gut_anaerobe_depletion.py` | Current anaerobe-side v2 depletion analysis across all body sites. |

Each v2 folder also includes `condition_body_site_guild_map.png` and
`condition_body_site_guild_map_edges.tsv`, generated by
`scripts/create_condition_body_site_guild_maps.py`. These maps connect
condition labels to anatomical body-site groups with edge width showing
focus-direction profile support and edge color showing the focus-minus-comparator
mean trait z-score. Node labels include `s=` for unique study support, and the
PNG subtitles/legends define `n=` as profile support and `bg=` as background or
comparator-profile support where applicable. The
companion `condition_body_site_guild_map_sampled_body_sites.tsv` files list all
sampled condition/body-site pairs after label filtering, including sampled body
sites that were not drawn as enriched edges in the PNG.

The paired-contrast trait-stat files include the pooled analysis, explicit
Feces-only and Feces-excluded analyses, and one file per body-site group with at
least 50 matched pairs. The manifest lists the emitted strata, pair counts, and
file paths. Pooled and per-stratum TSVs include every trait that passes the
analysis-set support and variance filters; they are not capped to the top 60
variable traits.

`all-bugsigdb-condition-body-site-maps/` contains increased-profile and
decreased-profile condition/body-site maps generated from all human-host
BugSigDB profile metadata in the current plotted corpus. These maps are
direction-support summaries rather than selected-trait enrichment maps: edge
width is focus-direction profile support, edge color is focus direction balance
against the opposite profile direction, and the subtitles/legends define `n=`,
`s=`, and `bg=` units directly in the PNGs.

`parkinsons-disease/` is generated by
`scripts/analyze_parkinsons_disease_trait_profiles.py` as part of the current
orchestrated refresh. It uses the same human-host study trait-profile heatmap
outputs as the v2 investigation scripts.

## Interpretation Rules

- The v2 trait-enrichment panels are trait-score summaries, not new differential
  abundance estimates.
- Target-taxon panels are audit and recurrence views for fixed NCBI Taxonomy ID
  lists; they do not define the trait-enrichment score.
- The parent comparison is aerobe trait enrichment in increased profiles versus
  anaerobe trait enrichment in decreased profiles.
- Off-diagonal cells in `profile_enrichment_guild_direction_grid.tsv` are
  guardrails: the aerobe trait-set score in decreased profiles checks for
  generally high aerobe signal, and the anaerobe trait-set score in increased
  profiles checks for mixed anaerobe signal.
