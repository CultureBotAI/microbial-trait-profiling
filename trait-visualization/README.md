# Trait Visualization Outputs

This folder contains clustered heatmap outputs for exploring BugSigDB-relevant taxa,
study profiles, and condition-level microbial trait patterns.

For a combined methods description of all clustered heatmaps and downstream
investigation figures, see `figure_methods.md`.

## Visualizations

### Taxa guild discovery

Files:

- `taxa_guild_discovery_clustered_heatmap.png`
- `taxa_guild_discovery_clustered_heatmap_matrix.tsv`
- `taxa_guild_discovery_taxa_metadata.tsv`
- `taxa_guild_discovery_trait_metadata.tsv`

Generated by:

```bash
uv run python scripts/create_taxa_guild_heatmap.py
```

This clusters high-support BugSigDB leaf-level taxa by their trait vectors. The
generator requests `strain` rows first, then falls back to `species` when no
strain rows are present in the current BugSigDB raw export. The current rendered
heatmap uses species-level taxa because `data/raw/full_dump.csv` contains no
MetaPhlAn `t__` strain leaves. It is intended to reveal taxa that share similar
biological, ecological, or phenotypic traits even when they appear in different
studies.

### Study trait profile clustering

Files:

- `study_trait_profile_clustered_heatmap.png`
- `study_trait_profile_clustered_heatmap_matrix.tsv`
- `study_trait_profile_study_metadata.tsv`
- `study_trait_profile_trait_metadata.tsv`

Generated by:

```bash
uv run python scripts/create_study_trait_profile_heatmap.py
```

This clusters every BugSigDB study/experiment/direction trait profile rather
than aggregating increased and decreased profiles together at the study level.
The full matrix and row metadata include the study ID, experiment ID, and inc/dec
direction for all 12,108 profiles from all 1,924 studies. To keep the PNG from
washing out to gray, the rendered image averages adjacent clustered profiles into
320 direction-specific display bins by default while keeping increased and
decreased sections separate. Use `--display-max-rows` to change the rendered bin
count without changing the full per-profile TSV outputs.

### Condition/disease trait modules

Files:

- `condition_trait_module_clustered_heatmap.png`
- `condition_trait_module_clustered_heatmap_matrix.tsv`
- `condition_trait_module_group_metadata.tsv`
- `condition_trait_module_trait_metadata.tsv`

Generated by:

```bash
uv run python scripts/create_condition_trait_module_heatmap.py
```

This groups studies by condition and body site, aggregates trait profiles within
each group, and clusters the resulting condition-level modules. It is intended to
highlight condition-specific trait signatures.

### BugSigDB taxa-only heatmaps

Folder:

- `bsdb-taxa-only/`

Generated by:

```bash
uv run python scripts/create_clustered_heatmap.py

```

This subfolder contains earlier heatmaps based directly on BugSigDB taxa
presence/absence and condition-by-genus prevalence.

## Interpreting Heatmap Colors

For the trait-profile heatmaps, red and blue are column z-scores computed from
log-scaled trait fractions:

1. For each study/experiment/direction row, raw trait counts are converted to
   fractions of that row's total trait count.
2. Fractions are scaled per 1,000 counts and transformed with `log1p`.
3. Each trait column is standardized to a z-score across plotted rows.

The PNG color scale is capped at +/-1 for readability. The matrix TSV stores the
exact per-profile z-score values; display binning is only used to render a
readable PNG.

- Red means a row has more of that trait than the average plotted row.
- Blue means a row has less of that trait than the average plotted row.
- White or pale gray means the row is near average for that trait.

These colors do not mean good/bad or increased/decreased abundance. They are
relative trait-profile signals within the plotted subset.

For binary taxa-trait heatmaps, teal cells indicate trait presence and white cells
indicate trait absence or no annotation.

## Source Data

The visualizations are generated from derived BugSigDB and trait tables:

- `data/derived/taxa.tsv`
- `data/derived/taxa_trait_matrix.tsv`
- `data/derived/taxa_trait_matrix_columns.tsv`
- `data/derived/study_trait_profiles_wide.tsv`
- `data/derived/studies.tsv`
- `data/raw/full_dump.csv`

The plotted TSV files in this folder contain the exact matrices and metadata
used for analysis. The study-trait-profile PNG is a binned rendering of the full
profile matrix to avoid preview/downsampling artifacts.
